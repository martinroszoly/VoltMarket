# VoltMarket

Magyar nyelvű elektronikai webshop és könnyű karrierjáték. A projekt nem használ valódi pénzt vagy fizetési rendszert; minden összeg játékbeli kredit.

## Indítás VS Code-ban

1. Csomagold ki a ZIP-fájlt.
2. Nyisd meg a `VoltMarket-main` mappát VS Code-ban.
3. Telepítsd a VS Code **Live Server** bővítményét.
4. Kattints jobb gombbal az `index.html` fájlra, majd válaszd az **Open with Live Server** lehetőséget.

Külön telepítés vagy `npm install` nem szükséges.

## Funkciók

- vörös, futurisztikus videojáték-stílus;
- termékkeresés és kategóriaszűrés;
- virtuális kosár és kreditfizetés;
- teljesíthető munkák, várakozási idő és jutalmak;
- felszerelés-alapú munkafeloldás és bevételi bónuszok;
- szintek és tapasztalati pontok;
- tranzakciós előzmények;
- automatikus mentés a böngésző localStorage tárhelyére;
- reszponzív mobilnézet.
- hibás telefonok, laptopok és PC-k felvásárlása;
- alkatrészpiac, gyors gépelős diagnosztika és összeszerelési minijáték;
- megjavított eszközök értékesítése játékbeli haszonnal.
- ingyenes technológiai jutalomkerék 10 perces, mentett várakozási idővel;
- használt, normál és prémium alkatrészminőségek;
- 10. szinten feloldható konzol-, VR- és játékkormány-szerviz;
- gaming technológiákhoz és szinthez kötött haladó munkák;
- egyszer teljesítendő diagnosztikai feladatok;
- valós gyorsítás alapján számolt és kijelzett munkaidő.

## A meglévő GitHub-oldal frissítése

1. Először teszteld a projektet VS Code-ban a Live Serverrel.
2. Nyisd meg a GitHubon a meglévő `VoltMarket` repositoryt.
3. Válaszd az **Add file → Upload files** lehetőséget.
4. Töltsd fel a kicsomagolt mappa tartalmát: `index.html`, `app.js`, `workshop.js`, `styles.css`, `README.md` és az `assets` mappa.
5. A feltöltés alján válaszd a **Commit changes** lehetőséget.
6. A GitHub Pages néhány percen belül ugyanazon a címen frissíti az oldalt.

Fontos: a repositoryba a fájlok kerüljenek közvetlenül, ne egy újabb `VoltMarket-main` almappába. Így az `index.html` továbbra is a repository legfelső szintjén marad.
