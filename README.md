# VoltMarket

Magyar nyelvű elektronikai webshop és könnyű karrierjáték. A projekt nem használ valódi pénzt vagy fizetési rendszert; minden összeg játékbeli kredit.

## Indítás VS Code-ban

1. Csomagold ki a ZIP-fájlt.
2. Nyisd meg a `voltmarket` mappát VS Code-ban.
3. Telepítsd a VS Code **Live Server** bővítményét.
4. Kattints jobb gombbal az `index.html` fájlra, majd válaszd az **Open with Live Server** lehetőséget.

Külön telepítés vagy `npm install` nem szükséges.

## Funkciók

- vörös, futurisztikus videojáték-stílus;
- termékkeresés és kategóriaszűrés;
- virtuális kosár és kreditfizetés;
- teljesíthető munkák, várakozási idő és jutalmak;
- felszerelés-alapú munkafeloldás és bevételi bónuszok;
- szintek és tapasztalati pontok;
- tranzakciós előzmények;
- automatikus mentés a böngésző localStorage tárhelyére;
- reszponzív mobilnézet.
- hibás telefonok, laptopok és PC-k felvásárlása;
- alkatrészpiac, gyors gépelős diagnosztika és összeszerelési minijáték;
- megjavított eszközök értékesítése játékbeli haszonnal.
